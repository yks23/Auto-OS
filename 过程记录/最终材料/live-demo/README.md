# StarryOS Live Demo Entry Points

This directory provides the short live-demo paths for the final presentation.
The canonical implementations live under `过程记录/最终材料/final/live-demo`; these
files are thin wrappers so the `final` and `live-demo` entry points stay in
sync.

Run from the repository root:

```bash
bash 过程记录/最终材料/live-demo/01-build-starryos --check
bash 过程记录/最终材料/live-demo/02-guest-build-starryos --check
bash 过程记录/最终材料/live-demo/03-test-kernel-result --check
bash 过程记录/最终材料/live-demo/04-try-kernel --check
bash 过程记录/最终材料/live-demo/05-speed-ratios --check
```

The full command order and speed-number explanations are documented in
`过程记录/最终材料/final/live-demo/README.md`.
